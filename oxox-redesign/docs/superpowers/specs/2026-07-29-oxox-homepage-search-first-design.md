# OXOX 首页“搜索优先”改版设计

## 目标

OXOX.CN 正式定位为“乐清外贸出口数据平台”。首页的第一目标是让访客输入企业名称，直接进入该企业的累计出口排名查询；图片处理、WebP 转换等工具降为辅助入口。

## 首页信息架构

1. 顶部导航：OXOX 标志、“出口排名”、“数据周期”、“辅助工具”。
2. 第一屏：
   - 定位标签：`YUEQING EXPORT DATA / 乐清出口数据`
   - 主标题：`查询乐清企业出口排名`
   - 简介：说明页面提供累计出口排名、出口额区间、环比及同比记录，不展示未经来源确认的精确金额。
   - 大型企业搜索框：支持企业名称和企业编号，提交后进入排名页并自动显示筛选结果。
   - 最新周期卡：展示 `2026年1—6月`、`3,180 条排名记录`、`11 个出口额区间`、`已收录 7 个周期`。
3. 排名预览：展示最新周期前三名企业、出口额区间和同比/较上期变化，提供“查看完整排名”入口。
4. 数据能力说明：强调累计周期切换、企业跨期档案和排名变化，不推算精确出口额。
5. 辅助工具：以紧凑卡片展示商品图尺寸处理与 WebP 转换，不再作为首页主视觉。
6. 页脚：保留大型 OXOX 标志和“乐清出口数据”定位。

## 交互

- 首页搜索提交后跳转到 `/yueqing-export-ranking/?q=<企业名称或编号>`。
- 排名页读取 `q` 参数，自动填入搜索框并筛选结果。
- 排名预览数据从现有 `2026-ytd-06.json` 中读取或在构建时固定为同源数据，避免手工复制产生偏差。
- 所有入口均支持键盘操作；动画遵守 `prefers-reduced-motion`。

## 视觉方向

- 沿用现有米白纸张、墨绿、橙色、黄色与颗粒纹理。
- 保留 OXOX 标志圆点 hover 动效。
- 采用 A 稿的搜索主导结构，但不照搬其中虚构的精确出口额、目的地和产品类别。
- 首页主标题与搜索框形成第一视觉焦点；真实数据卡居右；工具模块明显降低视觉权重。
- 桌面端为不对称双栏，移动端按“标题—搜索—数据摘要—排名预览—辅助工具”顺序堆叠。

## 文案与 SEO

- 页面标题：`乐清出口企业排名查询｜乐清外贸出口数据｜OXOX`
- 页面描述：`查询乐清企业累计出口排名、出口额区间和历史名次变化，覆盖多个累计周期。`
- 首页正文统一使用“出口额”“累计排名”，不使用“进出口额”。
- 不添加没有来源支持的总出口额、目的地数量、产品类别或精确金额。

## 验收标准

- 首页第一屏的主要操作是企业搜索。
- 搜索企业名称或编号后，排名页自动显示相应结果。
- 最新周期、记录数、区间数、周期数与现有数据文件一致。
- 桌面端和移动端无横向溢出，键盘和触屏操作正常。
- 现有排名页、商品图工具和 WebP 工具功能不受影响。
- 自动化测试、Astro 构建和真实浏览器验收全部通过。
